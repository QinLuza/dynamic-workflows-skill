# dynamic-workflows

给 ZCode 动态工作流（`CreateWorkflow`）写脚本的技能：作者契约 + 判断层。出自 ZCode harness 的 bundled skills，MIT 开源。

## 目标

为了让 ZCode 更耐用，让强模型做自己擅长的事，让弱模型更配合强模型工作，主对话保持干净让上下文更耐用。

## 原理

在 ZCode 里，主对话和工作流分工，靠**自选模型**把词元花对地方：

- **主对话用强模型**：只做判断、写码、决策这类"必须想清楚"的活。
- **工作流用便宜模型**：开工作流时自选模型（如 GLM-5.3-Flash）并配低推理档，测试、评测、验证、批量入库这类杂活交给后台子代理。
- **交接不靠转述**：命令门禁看退出码，固定格式输出由脚本直接解析，长日志留在工作流侧，主对话只收摘要。
- **结果**：主上下文不被污染、不反复重读，省下的额度全部花在判断上。

## 文件

| 文件 | 内容 |
|---|---|
| `SKILL.md` | 技能本体：判断层（§1–15）+ 工具契约（§16）；含 2026-10-24 词元经济学修订 |
| `patterns.md` | 拓扑目录（流水线、评审、通道、洞等） |
| `examples.md` | 完整示例脚本 |

## 安装

三件套放进同一目录：`~/.agents/skills/dynamic-workflows/`。`SKILL.md` 里的 `${ZCODE_SKILL_DIR}` 即该目录。
